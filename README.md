# Dynamic Navigation via Randomized Incremental Proximal Algorithms  

## Project Overview  
This project presents a real-time dynamic navigation system using randomized incremental proximal algorithms. The algorithm is implemented in Python and visualized in Unity, with demonstrations showing the agent navigating complex environments.  

## Key Features  
**Incremental Optimization**: Processes one obstacle at a time using gradient descent and proximal operators.  
**Real-Time Performance**: Reduces latency and computational overhead compared to batch methods.  
**Unity Visualization**: Real-time 3D animation of agent movement and obstacle avoidance.

# 基于随机化增量近端算法的动态导航  
  
## 项目概述  
本项目提出了一种基于随机化增量近端算法的实时动态导航系统。该算法使用Python实现，并通过Unity进行可视化，展示了智能体在复杂环境中导航的过程。  

## 主要特点   
**增量优化**：利用梯度下降和近端算子逐一处理障碍物。  
**实时性能**：与批处理方法相比，降低了延迟和计算开销。  
**Unity可视化**：智能体运动及避障过程的实时3D动画。
